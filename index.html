TCID Image Renamer

Upload the Hex Tab 3 CSV and a folder of images. The tool finds filenames containing OLD_IMAGE_KEY, replaces that part with NEW_IMAGE_KEY, and exports a renamed ZIP plus a processing report.

1. Upload rename CSV

Use the Tab 3 export from Hex. Extra columns are kept in the report where possible.

2. Upload image folder

The app does not modify your local files. It creates a renamed ZIP output.

3. Processing options

Default behaviour is conservative: only RENAME_NEEDED rows are renamed automatically. Review rows are reported unless you choose to include them.
